# ППР-Бот (Telegram-бот для оповещения о планово-профилактических работах)

Telegram-бот для автоматического контроля и рассылки уведомлений о планово-профилактических работах (ППР) на ближайшие сутки. Бот загружает графики работ и справочник сотрудников из Google Таблиц, парсит их с помощью `pandas` (опционально с резервным разбором через ИИ) и в заданное время отправляет сводку в привязанный рабочий чат с упоминанием ответственных сотрудников.

## Основные возможности

* **Многопользовательский режим.** Один экземпляр бота обслуживает сразу несколько пользователей или отделов. Каждый зарегистрированный пользователь управляет собственными графиками ППР, личным справочником сотрудников и привязанным чатом для уведомлений независимо от других. Данные пользователей изолированы друг от друга.
* **Автоматические уведомления по расписанию.** Ежедневно в заданное время (`TIME_CHECK_TASKS`) бот проверяет актуальные задачи на ближайшие 24 часа и публикует их в привязанном чате пользователя.
* **Управление графиками ППР.** Загрузка, просмотр и удаление графиков на выбранный месяц через личные сообщения с ботом. Для одного пользователя на один месяц хранится только один график (для обновления старый график удаляется, после чего загружается новый).
* **Умный двухуровневый парсинг.** Бот выгружает Google Таблицу в формате CSV и разбирает её через `pandas`. Если структура таблицы нестандартная и `pandas` не справляется, данные автоматически отправляются на парсинг через ИИ (если заполнены параметры `AI_*`).
* **Справочник сотрудников с автотегами.** Справочник коллег загружается из Google Таблиц аналогичным способом. При публикации сообщения о работах бот находит исполнителей в справочнике и подставляет их ТГ-никнеймы в сообщение чате.
* **Отдельный пункт меню для формирования графика возможных дат для ППР при работе  отдела в графике 2/2.** Выгружает ночи попадающие в переход бригад с рабочей смены в выходной.
* **Встроенная поддержка прокси.** Поддержка работы через локальный прокси-туннель [TgWsApiProxy](https://github.com/winchanii/TgWsApiProxy) на базе Cloudflare Workers.
* **Админ-мониторинг и логирование.** Отдельный сервисный бот (`BOT_ADMIN`) для отправки системных уведомлений администратору (`TG_ADMIN`) и запись логов в файл.

## Стек технологий

* **Язык:** Python 3.10+
* **Telegram Bot API:** `aiogram` 3.24
* **База данных:** SQLite (`SQLAlchemy` async + `aiosqlite`)
* **Парсинг и анализ данных:** `pandas`
* **Интеграции:** Google Sheets API, OrcaRouter API (резервный ИИ-парсинг), `tgwsapiproxy` (опционально)

## Подготовка Google Таблиц

1. **Откройте доступ по ссылке.** Для всех таблиц (графиков ППР и справочника сотрудников) должен быть включён доступ **«Все, у кого есть ссылка — Читатель»**.
2. **Соблюдайте структуру шаблона.** График ППР должен соответствовать [шаблонной таблице](https://docs.google.com/spreadsheets/d/1gtyrOnho6NUiAYcvMld4lJ2IE7ygU6VhZWyxkGHGJFI/edit?usp=sharing) со следующими столбцами:
   * `№ задания`
   * `Дата и время` (формат `ДД.ММ.ГГГГ ЧЧ:ММ:СС`)
   * `Адрес`
   * `Тип работ`
   * `Исполнители`
3. **Структура шаблона справочника исполнителей**
   * `ФИО`
   * `Ник` 

## Установка и запуск через python

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/khristm/Bot_TG_Notification_of_PPR
   cd Bot_TG_Notification_of_PPR
   ```

2. **Создайте и активируйте виртуальное окружение:**
   ```bash
   python -m venv venv
   source venv/bin/activate  # Linux / macOS
   venv\Scripts\activate     # Windows
   ```

3. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Создайте файл `.env` из примера и заполните настройки:**
   ```bash
   cp .env.example .env
   ```

5. **Запустите бота:**
   ```bash
   python main.py
   ```
## Запуск на windows через .exe 

1. **Загрузите последнюю версию из Releases**
2. **Распакуйте архив в удобную для вас директорию**
3. **Переименуйте файл .env.example в .env и заполните его**
4. **Запустите файл .exe**


## Конфигурация (.env)

| Переменная | Обязательна | Описание                                                                                                                                 |
| :--- |:-----------:|:-----------------------------------------------------------------------------------------------------------------------------------------|
| `TOKEN_BOT` |     Да      | Токен основного Telegram-бота от `@BotFather`                                                                                            |
| `BOT_ADMIN` |     ДА      | Токен второго бота для отправки технических оповещений о работе системы                                                                  |
| `TG_ADMIN` |     ДА      | Telegram ID администратора для получения системных уведомлений(ваш id в ТГ)                                                              |
| `PROXY_WS_URL` |     Нет     | Адрес Cloudflare Worker для проксирования запросов через [TgWsApiProxy](https://github.com/winchanii/TgWsApiProxy), без указания прокси запуск в обычном режиме |
| `API_KEY` |     Да      | Ключ Google API для доступа к Google Таблицам                                                                                            |
| `AI_TOKEN` |     Нет     | API-токен сервиса [OrcaRouter](https://orcarouter.ai) для резервного парсинга через ИИ или любого другого сервиса с ИИ                   |
| `AI_API_URL` |     Нет     | URL REST API для ИИ-парсинга (например, `https://api.orcarouter.ai/v1`)                                                                         |
| `AI_MODEL` |     Нет     | Идентификатор модели ИИ (например, `orcarouter/auto` или `openai/gpt-4o-mini`)                                                           |
| `DB_PATH` |     Да      | Путь к файлу базы данных SQLite (по умолчанию `DB.db`)                                                                          |
| `TIME_CHECK_TASKS` |     Да      | Время ежедневной проверки и отправки задач на ближайшие сутки (например, `09:05`)                                                        |
| `PATH_LOG` |     Да      | Путь к файлу логов (по умолчанию `work_log.log`)                                                                                         |
| `LOG_LEVEL` |     Да      | Уровень логирования (`INFO`, `DEBUG`, `WARNING`, `ERROR`)                                                                                |
| `HELLO_MSG` |     Да      | Приветственное сообщение бота по команде `/start`                                                                                        |


## Использование

1. **Регистрация в боте.** Откройте личный чат с ботом, отправьте `/start` и пройдите регистрацию.
2. **Привязка группового чата.** Добавьте бота в рабочий чат отдела, выдайте ему права на отправку сообщений и выполните команду `/lock_chat`.
3. **Работа с графиками ППР.**
   * **Добавить график:** выберите месяц и отправьте ссылку на заполненную Google Таблицу.
   * **Просмотреть график:** запросите расписание на нужный месяц прямо в боте.
   * **Обновить график:** удалите старый график за выбранный месяц и загрузите новую ссылку.
4. **Загрузка справочника сотрудников.(Необязательно)** Через меню бота в личных сообщениях загрузите ссылку на Google Таблицу со списком сотрудников и их Telegram-никнеймами. Через отдельный пункт меню справочник можно просмотреть, при повторной загрузке справочник заменится.
5. **Даты для ночных ППР** Через меню бота перейдите в соответствующий раздел. Выберите месяц и дату первой полной двухдневной смены в месяце любой бригады, бот в ответ сформирует список ночей доступных для ППР для обеих бригад отсекая выходные дни.
